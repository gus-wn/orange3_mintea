# 개인에 관한 신상정보로 소득 정도를 예측할 수 있을까?

Kaggle「Korea Income and Welfare」데이터를 Orange3로 탐색하고 회귀 모델(Linear Regression, kNN, Random Forest)로 소득을 예측하는 수업 자료입니다.

- `lesson.html` 수업 자료 (단계별 설명, 화면 캡처, 상관계수 체험)
- `worksheet.html` 학생용 웹 학습지 (빈칸·선택 문항 자동 채점, 서술형, 답안 복사)
- `img/` 오렌지3·캐글 화면 캡처

원자료: 황은아(구미산동고), 『데이터 기반 인공지능 교육 자료』 35–52쪽을 재구성했습니다.
