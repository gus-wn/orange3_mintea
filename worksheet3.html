탐구 질문과 데이터 고르기

Kaggle

알아두기 · 좋은 데이터 고르는 법

  • CSV 파일로 내려받을 수 있는 데이터를 고릅니다. (캐글 검색 화면 왼쪽 Filters → File Type: CSV)
  • 행(데이터 수)이 100개 이상, 속성(열)이 5개 이상이면 분석하기 좋습니다.
  • 맞히고 싶은 값(target)이 분명해야 합니다. 숫자면 회귀, 종류면 분류 문제가 됩니다.
  • 데이터 페이지의 License를 확인하고, 출처를 꼭 적습니다.
  • 실제 사람의 이름, 연락처 같은 개인정보가 들어 있는 데이터는 피합니다.

캐글 데이터 찾아보기 ↗

내 탐구 질문은 무엇인가요? (예: 공부 시간과 수면 시간으로 시험 점수를 예측할 수 있을까?)

고른 데이터의 정보를 적어 봅시다.

이 데이터를 고른 까닭과, 이 데이터로 무엇을 알아낼 수 있을지 써 봅시다.

1단계

데이터 전처리

File · Data Table · Select Columns · Select Rows · Impute · Feature Constructor

데이터의 속성을 정리해 봅시다. (속성이 많으면 '줄 추가'를 누르세요. target은 꼭 넣어 주세요.)

속성 이름뜻TypeRole

내 탐구는 어떤 문제인가요? 그렇게 판단한 까닭도 써 봅시다.

전처리에 사용한 위젯에 체크하고, 무엇을 왜 처리했는지 써 봅시다.

2단계

상관관계 파악

Distributions · Box Plot · Scatter Plot · Correlations · Rank

관계를 살펴볼 때 사용한 위젯에 체크해 봅시다.

target과 관련이 큰 속성은 무엇이었나요? 그래프나 숫자(상관계수, Rank 점수 등)를 근거로 써 봅시다.

학습에 사용할 속성을 고르고, 고른 까닭을 써 봅시다.

3단계

모델 학습

Data Sampler · Model 위젯

타겟 변수 설정

학습 데이터와 테스트 데이터를 어떻게 나눴나요?

학습시킨 모델에 모두 체크해 봅시다. (두 가지 이상)

내 워크플로 전체 화면을 캡처해 올려 봅시다.

4단계

결과 검증

Test and Score · Confusion Matrix · Predictions

Test and Score 결과를 적어 봅시다. 첫 줄에 지표 이름을 쓰세요. (회귀: R², RMSE, MAE · 분류: CA, F1, Precision)

모델

가장 성능이 좋은 모델은 무엇이고, 어떤 지표를 근거로 판단했나요?

테스트 데이터로 예측한 결과(Predictions)나 Confusion Matrix를 보고, 모델이 잘 맞힌 경우와 틀린 경우를 해석해 봅시다.

5단계

결론과 성찰

탐구 질문에 대한 나의 결론을 데이터 근거와 함께 써 봅시다.

이번 분석의 한계는 무엇이고, 다시 한다면 무엇을 바꾸고 싶나요? (데이터 양, 속성, 모델, 설정 등)

내 모델을 실제로 쓴다면 어떤 문제(공정성, 개인정보, 잘못된 예측의 피해 등)가 생길 수 있을까요?

수행평가를 하며 새로 배운 점이나 어려웠던 점을 자유롭게 써 봅시다.
