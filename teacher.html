  1. GitHub 토큰 만들기 페이지를 엽니다. (GitHub 로그인 필요)
  2. Token name에 밍티 편집기, Expiration은 원하는 기간을 고릅니다.
  3. Repository access에서 Only select repositories → orange3_mintea만 고릅니다.
  4. Permissions → Repository permissions에서 Contents를 Read and write로 바꿉니다.
  5. Generate token을 누르고, 나온 토큰(github_pat_로 시작)을 복사해 아래에 붙여 넣습니다.
