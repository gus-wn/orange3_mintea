데이터 분석

학습 목표
  • Orange3를 설치하고 위젯을 연결해 데이터를 불러올 수 있다.
  • 위젯으로 표를 고르고 고치며, 대푯값과 분포를 그래프로 확인할 수 있다.
  • 선형 회귀 모델로 새로운 데이터의 결과를 예측할 수 있다.
생각 열기

코딩 없이 데이터를 다룰 수 있을까?

Orange3는 코드를 쓰지 않고 끌어다 놓기(드래그 앤 드롭)만으로 데이터를 분석하는 도구입니다. 표를 고치고, 그래프를 그리고, 머신러닝 모델까지 만들 수 있습니다.

오늘은 수학 원리를 모두 파헤치기보다 입력 → 처리 → 출력을 직접 경험해 보면서, 머신러닝이 얼마나 쓸모 있는 도구인지 빠르게 살펴봅니다.

우리 생활에서 '데이터를 보고 앞으로를 예측'하는 경우를 하나 떠올려 써 봅시다. (예: 날씨에 따라 아이스크림을 얼마나 준비할까?)

활동 1

Orange3 설치하기

orangedatamining.com
  1. orangedatamining.com에 들어가 위쪽 메뉴의 Download를 누릅니다.
  2. 내 컴퓨터에 맞는 운영체제(Windows / macOS)를 고르고 설치 파일을 내려받습니다. 용량이 수백 MB라 시간이 조금 걸립니다.
  3. 설치 파일을 실행해 안내대로 설치하고, Orange를 실행합니다. 시작 창에서 New를 누르면 빈 캔버스가 열립니다.
학교 컴퓨터에서 설치가 안 될 때관리자 권한이 필요하면 선생님께 말씀드리세요. 이미 설치된 컴퓨터라면 시작 메뉴에서 'Orange'를 검색해 실행하면 됩니다.

내가 마친 단계에 체크해 봅시다.

위젯 묶음과 하는 일을 알맞게 연결해 봅시다.

오늘의 데이터: 레모네이드 판매 기록

레모네이드 가게의 5일 동안의 기록입니다. 날마다 날짜, 요일, 온도, 판매량, 가게 문을 연 시간을 적었습니다.

  1. Data 묶음의 File 위젯을 캔버스에 놓고 더블클릭합니다.
  2. URL을 고르고 아래 주소를 붙여 넣은 뒤 Enter를 누릅니다. 바로 안 뜨면 Reload를 누릅니다.
    https://gus-wn.github.io/orange3_mintea/data/lemonade.csv
  3. File 오른쪽 곡선을 끌어 Data Table을 연결하고, 더블클릭해 표를 확인합니다.
구글 시트로 내 데이터를 불러오고 싶다면 구글 시트에서 공유 → 링크가 있는 모든 사용자로 바꾼 뒤 링크를 복사해 File의 URL 칸에 넣으면 됩니다. 공개하지 않은 시트는 오렌지3가 읽을 수 없습니다.

Data Table을 보고 빈칸을 채워 봅시다.

이 데이터는 개의 행(날)과 개의 열로 되어 있다. 온도가 1도 오를 때마다 판매량은 개씩 늘었다.

활동 3

표 다루기

Select Rows · Select Columns · Feature Constructor

① Select Rows: 원하는 행만 골라내기

  1. File에 Select Rows를 연결하고 더블클릭합니다.
  2. 조건을 판매량 · is below · 44로 정합니다. (판매량이 44 미만인 날)
  3. Select Rows에 Data Table을 하나 더 연결해 골라낸 행을 확인합니다.
  4. 또 다른 Data Table을 연결하고, 연결선을 더블클릭해 Unmatched Data → Data로 바꿔 봅니다. 조건에 맞지 않아 걸러진 행이 보입니다.

Select Rows 결과를 적어 봅시다.

조건에 맞는 행(Matching Data)은 개, 걸러진 행(Unmatched Data)은 개이다.

② Select Columns: 보고 싶은 열만 남기기

Select Columns를 열면 왼쪽(Available Variables)은 숨길 열, 오른쪽(Features)은 보일 열입니다. 보고 싶은 열을 오른쪽으로, 보고 싶지 않은 열을 왼쪽으로 옮깁니다.

③ Feature Constructor: 새 열 만들기

레모네이드 한 잔이 5,000원이라면 하루 매출은 얼마일까요? Feature Constructor에서 New → Numeric을 고르고, 이름을 매출, 식을 판매량*5000으로 적은 뒤 Send를 누릅니다. 뒤에 Data Table을 연결하면 매출 열이 생긴 것을 볼 수 있습니다.

판매량이 46인 날의 매출은 얼마일까요?

활동 4

통계와 시각화

Box Plot · Scatter Plot

알아두기 · 대푯값과 분포

대푯값은 데이터 전체를 숫자 하나로 나타낸 값입니다. 평균(모두 더해 개수로 나눈 값), 중앙값(크기 순으로 세웠을 때 가운데 값), 최빈값(가장 많이 나온 값)이 있습니다.

하지만 대푯값만으로는 데이터가 어떻게 퍼져 있는지(분포)를 알 수 없습니다. 학생이 2명뿐인 두 반이 있는데, 1반은 100점과 0점, 2반은 50점과 50점이라면 평균은 둘 다 50점이지만 모습은 전혀 다릅니다. 이 차이를 보려고 사분위수, 분산, 표준편차를 씁니다.

다음 판매량 데이터의 대푯값을 구해 봅시다. 30, 42, 43, 47, 58

평균 중앙값

① Box Plot: 퍼진 정도 보기

  1. File에 Box Plot을 연결하고 변수에서 판매량을 고릅니다.
  2. File을 하나 더 놓고 아래 주소(판매량이 다른 데이터)를 불러와 Box Plot을 또 연결합니다.
    https://gus-wn.github.io/orange3_mintea/data/lemonade2.csv
  3. 두 상자 그림을 비교합니다. 파란 막대 위의 44 ± 2.8은 평균과 표준편차, 노란 선은 중앙값입니다.

두 데이터는 평균이 44로 같습니다. 상자 그림에서 무엇이 달랐나요? 레모네이드 가게 주인이라면 어느 쪽이 재료를 준비하기 쉬울지도 함께 써 봅시다.

힌트±뒤의 숫자(표준편차)와 상자의 길이를 비교해 보세요. 매일 판매량이 비슷한 가게와 들쭉날쭉한 가게 중 어디가 계획을 세우기 쉬울까요?

② Scatter Plot: 관계 보기

File에 Scatter Plot을 연결하고 x축을 온도, y축을 판매량으로 바꿔 봅니다. 산점도로는 두 값의 관계, 다른 점들과 동떨어진 이상치, 점이 모여 있는 군집을 볼 수 있습니다.

온도와 판매량을 산점도로 그리면 점들이 어떤 모양으로 놓이나요?

활동 5

온도로 판매량 예측하기

Linear Regression · Predictions

알아두기 · 원인과 결과

원인이 되는 값을 독립변수, 결과가 되는 값을 종속변수라고 합니다. 이미 있는 원인과 결과로 규칙을 배우게 한 뒤, 새로운 원인만 주고 결과를 맞히게 하는 것이 머신러닝의 지도학습입니다. 결과가 숫자이면 회귀라고 부릅니다.

오렌지3에서는 File 위젯의 Columns에서 각 열의 Role(역할)을 정합니다.

Role과 뜻을 알맞게 연결해 봅시다.

  1. 처음 File을 더블클릭해 Role을 날짜 meta, 온도 feature, 판매량 target, 오픈시간·요일 skip으로 바꿉니다.
  2. Model 묶음의 Linear Regression을 File에 연결합니다. 이제 모델이 온도와 판매량 사이의 규칙을 배웁니다.
  3. 새 File을 하나 놓고 예측할 날의 데이터를 불러옵니다. 판매량이 없는 데이터입니다.
    https://gus-wn.github.io/orange3_mintea/data/lemonade-new.csv
  4. Evaluate 묶음의 Predictions에 새 File(Data)과 Linear Regression(Model)을 연결하고, 뒤에 Data Table을 붙여 예측값을 확인합니다.
